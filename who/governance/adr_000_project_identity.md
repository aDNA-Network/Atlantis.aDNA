# ADR-000 — project identity (proposed)

**Decision (proposed).** `Atlantis.aDNA` is a **Framework + reference platform**: the fleet's home for the
sepsis-analog method of ocean/aquatic ecosystem early warning — doctrine, patterns, templates, skills and
public-data exemplars — consumed by **data-bearing regional instance graphs** that federate it. Atlantis is
**not data-bearing** (SO-3). Persona **Proteus**. Codename **Operation Tidewatch**. Public, MIT, at
`aDNA-Network/Atlantis.aDNA`.

**Lineage.** Spun out whole from the aDNALabs S329 pilot (2026-09-23), which becomes the exemplar
`what/exemplars/gulf_karenia_brevis/`. Distinct from: `Exchange.aDNA` (commons/market), `Ingest.aDNA` (intake),
`Molecules.aDNA` (molecular forge), `WorldGenome.aDNA` (genome org), `Datasets.aDNA` (dataset primitive).

**Name-form.** `Atlantis` capitalised, matching every other project in the fleet; recorded as the standing
ADR-009 §3 exception (see `who/coordination/coord_2026_09_23_name_form_note.md`).

**Consequences.** Instances own their data posture and rulings; Atlantis owns the method; improvements return
as patterns and templates, never as data. Every published page from an instance carries a Limitations section.

**Alternatives considered.** Platform (single data-bearing system): rejected as centralising. Forge: rejected as
under-serving doctrine and context. Keeping the pilot in aDNALabs: rejected by the operator on 2026-09-23.
