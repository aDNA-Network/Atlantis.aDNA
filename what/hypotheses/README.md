# The hypothesis ledger

The **MPA knowledge graph**, in Atlantis's terms: not a graph of observations (those stay in instances) but a graph of
**what the literature claims drives an event** — mechanism · driver · lag · direction · threshold · ecosystem type ·
evidence class · citation — each row pointing at a sentence, each row realisable as an `AtlVital` candidate, and
each realised row *tested* by the model. A feature the papers insist on that carries no SHAP is a finding worth
writing up; so is one that does. This is playbook §C made into a registry.

**Status: built at M-3b-i (2026-10-12).** The row is `AtlHypothesis` in `atl_v0` 0.9.0 (controlled: 25 controls, three
worlds); `atlantis_core.hypotheses` fetches the corpus, checks every row and generates `LEDGER.md`; the reading is
`how/skills/skill_feature_hypothesis_mining.md`. The first ledger is `coral_reef`, read for FKNMS's DHW-onset event. This
README fixes the extraction target so the lane produces a table, not prose.

```
what/hypotheses/
├── README.md                      this spec
├── LEDGER.md                      GENERATED — python -m atlantis_core.hypotheses --index [--check]
├── ledger/<ecosystem_type>/<hyp_id>.yaml          one row per file, validated -C AtlHypothesis
├── withdrawn/<ecosystem_type>/<hyp_id>.yaml       rows a reader showed the text cannot carry — archived, never deleted (SO-2); not checked
├── realisation_<ecosystem>_<date>.md              the hand-off: the rows ranked for an instance, and the operator's pick

    ├── queries.yaml               the recipe (committed)
    ├── manifest.yaml              the retrieval record — metadata only (committed; GENERATED by `… corpus`)

```

## A row

`what/hypotheses/ledger/<ecosystem_type>/<hyp_id>.yaml` — one hypothesis per file (greppable, diffable, memo-able).
The shape is `AtlHypothesis` (atl_v0 0.9.0, closed). Three driver keys carry a prefix (`driver_lag`, `driver_direction`,
`driver_threshold`) because `lag`, `direction` and `threshold` are already slots of other ranges in the ontology:

```yaml
hyp_id: atl_hyp_<ecosystem>_<driver>_<nnn>
tier: draft                        # draft → reviewed (a second reader; reviewed_by required) · validated: not yet (one reviewer slot)
ecosystem_type: coral_reef         # closed; ENVO biome-bound: coral_reef ENVO:01000049 · estuary ENVO:01000020 · neritic_pelagic ENVO:01000042
event_variable: "<degree_heating_week | a WoRMS taxon | …>"
mechanism: "<one sentence, the paper's claim in the paper's terms>"
driver:
  variable: "<CF name / index / taxon>"
  authority: "<CF:… | NOAACRW:… | producer>"
  driver_lag: {lag_value: <n ≥ 0>, lag_unit: days|weeks|months|years, lag_note: "as stated | inferred: <how> | not stated — concurrent"}
  driver_direction: positive | negative | nonmonotone | threshold
  driver_threshold: {threshold_value: <n>, threshold_unit: "<UCUM>"}   # optional
region_asserted: "<where the paper looked>"
evidence_class: observational | experimental | model | review | agency_report
citation: {doi: "<bare 10.x/…>", title: "<…>", year: <n>, citation_source: openalex | semantic_scholar | europe_pmc | agency}   # or url: for a work with no DOI
sentence_pointer: 'abstract: "<≤ 25 words, verbatim>"'   # or a locator ("Results ¶2"); a quotation is checked against the cached abstract
hypothesis_source: literature        # literature | steward_expert | model_finding (a SHAP surprise promoted to a hypothesis)
realisable_as: "<stream class · transform · lag>"   # or "unrealisable: <why>" — T8's falsifier, visible per row
realisability: declared_fetcher      # existing_stream | declared_fetcher | new_stream | unrealisable — counted by LEDGER.md
realisation:                         # on every row; filled when an instance turns the row into a vital
  result: untested                   # untested | supported | not_supported | inconclusive
  # realised_in · realised_vital (atl_vital_…) · realised_stream (atl_stream_…) · tested_at · shap_mean_abs · write_up
recorded_by: agent_<persona>
recorded_at: "YYYY-MM-DDTHH:MM:SSZ"
reviewed_by: agent_<other>           # required when tier: reviewed; never the extractor (core check)
reviewed_sha256: <hex64>             # written by --stamp-review: binds `reviewed` to the paper-facing fields the reader read
```

## Rules

1. **Every row points at a sentence.** No pointer, no row.
2. **A row is a hypothesis, not a fact.** `tier: validated` means two reviewers agree the extraction is faithful to
   the paper — not that the mechanism is true. Truth is the instance's SHAP and the write-up's job.
3. **Realisation closes the loop both ways.** `result: not_supported` rows are kept and written up (T8).
4. **No private data in a row.** A steward-expert hypothesis (`hypothesis_source: steward_expert`) carries the
   steward's consent to be named or is attributed to the instance.
5. **Ecosystem type is the join key** across instances: a coral DHW driver asserted in Palau is a candidate vital in
   the Keys; the ledger is how P2's FKNMS instance inherits P3's reading.
6. **Intake composes `Ingest.aDNA`** when a corpus exists (OpenAlex / Semantic Scholar / Europe PMC / agency
   bulletins): discover → fetch → redact → gate → publish, with `unreviewed/` as a path, not a flag.

## Index

Generated, never hand-edited: **`LEDGER.md`** (`python -m atlantis_core.hypotheses --index`, from `what/atlantis_core/`).
`--index --check` fails on a stale ledger or on any row failure — the ledger renders only checked rows.
